01 / 最终结论

补充条件后继续：当前 result 已完成文献与方法适用性审查，正确区分了 Waddington-OT 与 StationaryOT 的输入前提，撤回了无来源的固定重复数门槛，并明确 M2/M3/M5 在当前单时期 bulk 条件下不可辨识、维持 rejected。唯一不与数据条件直接冲突的迁移路径是 M4 静态经验分布比较，但其实施以概率测度、代价函数、独立生物重复数、组织/批次可比性等要件为前提；这些关键数据条件在验收案例中全部缺失，且用户明确本轮不提供真实实验矩阵。因此当前不能进入数值 OT 实施，也不能宣布迁移成功；应保留 M4 为条件化候选路径，先补齐重复数、配对/批次、数据形态、分组定义与参考相容性等缺口，再按已定义的最小验证步骤决定是否实施。

修订后的研究假说：在仅具备单时期 bulk RNA-seq 与代谢组、且无法补采样或功能实验的验收案例条件下，最优传输的潜在增量仅可能体现在以 M4 方式定义的经验分布静态比较（Wasserstein 距离/重心）相对常规差异表达与常规距离基线的附加可解释性与稳定性；但这一增量是待验证假说，不成立的条件已被明确限定：Waddington-OT 的时间耦合/轨迹重建（M2）、依赖增长/死亡项的非平衡 OT（M3）、以及基于 OT 命运概率的混合身份 vs 跨分化判别（M5）在当前输入下均不可辨识，必须维持 rejected。此外，M1 所指的单细胞状态分布不能由 bulk 去卷积还原；去卷积最多估计细胞类型比例。若任一分组独立生物重复数、组织/批次可比性、概率测度或代价函数定义任一要件不满足，或 Wasserstein 距离相对常规距离无稳定增量，则应暂停 OT 实施并转入文献与设计审查结论。创新性方面，基于当前 5 篇选定文献只能做范围明确的查新：P4 已将 StationaryOT 用于拟南芥根单细胞图谱的命运概率推断，P5 在马铃薯钩状匍匐茎使用 Slingshot 拟时序；首轮'首次尝试'及'整个马铃薯领域未用 OT'的过度推断予以撤回，是否为首例需另行系统查新。

候选新增贡献：相对已有工作，本阶段候选新增贡献为：在明确排除 Waddington-OT 时间耦合、StationaryOT 稳态单快照及 OT 命运概率判别等不适用路径后，将马铃薯块茎发育多组学的 OT 迁移收敛为条件化的 M4 静态经验分布比较框架；提出以 P1 鉴定的淀粉-蔗糖代谢、α-亚麻酸代谢、氮代谢、ABC 转运体等通路清单作为 OT 状态空间与代价矩阵的生物学先验，或以全特征空间为对照；并建立以常规差异分析和常规距离为基线、以重采样稳定性与可解释性增量为判据的验证设计。该贡献属于方法迁移与验证框架设计，非方法学原创，且实施前必须补齐数据条件。

02 / 修订前后发生了什么

修订前的问题：能否引入最优传输，研究马铃薯块茎形成过程中多组学状态的变化，并提出可验证的发育机制假说？

修订前的判断：待验证迁移假说：把马铃薯块茎形成过程建模为匍匐茎→块茎转变中'多组学状态概率分布'的演化。若补充可比的时期采样(同一基因型、同一组织部位、足够生物重复)，则可用最优传输估计相邻时期状态分布间的输运耦合，从而(1)量化氮等处理下'源-库'状态转换的输运距离与路径，(2)识别驱动状态转移的关键细胞类型/通路(如淀粉与蔗糖代谢、ABC转运、α-亚麻酸代谢)，(3)提出可验证的发育机制假说，例如'缺氮通过加速韧皮部/淀粉合成细胞状态的Wasserstein重心向库端迁移而促进块茎起始'。该假说的可证伪点：在无时间序列或组织不可比时，OT推断的轨迹应退化为静态分布差异，不能产生有效的祖先-后裔关系。

本次修订：这是产品验收案例，不是用户真实实验数据。修订：仅有单时期bulk RNA-seq与代谢组，无法补采样/实验，接受将目标缩小为材料或处理之间的静态比较。先前M2时间耦合、M5命运判别前提不成立；M3没有增长/死亡数据，不能因此默认平衡OT。M1去卷积最多估计细胞类型比例，不等于还原单细胞状态分布。M4须先定义概率测度、代价函数并核查重复数；重复不足时应停止OT实施。请撤回首轮“首次尝试”及从一篇论文推断整个马铃薯领域未用OT的说法，创新性需要范围明确的查新。区分Waddington-OT与需要稳态、增长率等条件的StationaryOT。给出能改变决策的检查、最小基线与停止条件，不生成实验结果。 最新勘误（修订3，取代此前尚未执行的计划请求）：独立核对原始出版物后，P2应为DOI 10.1016/j.cell.2019.01.006，对应PII S009286741930039X、PMC6402800，摘要315000 profiles、18天；首轮8天/17时点/14.9万不沿用。P5正式卷期2026，在线2025；其Slingshot分析只能说明该文方法。当前选定paper与mapping已保留勘误来源。请依据最新输入审查与生成计划，忽略旧消息中的旧产物路径。

当前问题：在单时期 bulk RNA-seq 与代谢组条件下，最优传输能否为马铃薯处理或材料间的静态比较提供可验证的增量？

单细胞表达向量构成的概率分布(Waddington-OT/StationaryOT的分析单元) → 可比样本的特征向量构成的经验分布；若参考匹配，可另评估细胞类型比例｜待核实。成立条件：须定义概率测度、归一化与距离；去卷积仅估计比例，不等于恢复单细胞状态分布。

相邻时间点的时间耦合(temporal coupling)/祖先-后裔关系 → 块茎形成相邻发育时期(匍匐茎→钩状→膨大→成熟)样本状态分布间的输运耦合｜否定。成立条件：必须补充可比的时期采样(同基因型、同组织部位、足够生物重复、近似等间隔)，否则时间耦合不可辨识

非平衡OT中的细胞增殖/死亡增长项g(u) → 块茎起始中细胞分裂/扩张与源-库转变导致的组学'质量'不平衡｜否定。成立条件：增长/死亡率与质量解释未建立；缺少这些条件不能默认平衡OT成立。

Wasserstein距离/重心作为分布差异度量 → 处理或材料间的静态经验分布比较｜待核实。成立条件：须有足够独立生物重复、可比组织与批次，并明确概率测度/质量/代价函数；需与常规距离比较稳定性与增量，否则停止OT。

OT命运概率判别'混合身份vs跨分化'(P4范式) → 判别块茎起始细胞是'先混合后特化'还是'由匍匐茎某状态跨分化为库端细胞'｜否定。成立条件：依赖单细胞时间序列与可靠细胞类型注释；bulk数据下该判别不可行

03 / 具体发现与证据

【文献依据】Waddington-OT 与 StationaryOT 的输入前提在单时期 bulk 样本下不成立 Waddington-OT（P2）以相邻时间点的单细胞状态分布为分析单元，通过时间耦合重建重编程轨迹；其原文摘要报告 18 天内约 315000 个 scRNA-seq profiles，并实验验证 Obox6、GDF9。StationaryOT（P3）把 OT 推广到稳态群体的单快照，但需要群体近似稳态（∂tρ=0）、可估计的通量/增长率 R(x) 与噪声水平，且可辨识性依赖漂移为标量势梯度（v=−∇Ψ）的假设。两者均以单细胞分布为输入；当前仅单时期 bulk RNA-seq 与代谢组，不具备时间耦合或稳态单快照所需的单细胞状态分布与增长条件。因此 M2（时间耦合）、M3（增长/死亡项）、M5（命运概率判别混合身份 vs 跨分化）维持 rejected。单时期 bulk 不能作为所有 OT 方法的通用否决条件，但对 Waddington-OT 与 StationaryOT 的轨迹/命运推断目标而言，当前输入不满足其已声明的前提。 依据：[P2] [P3]

【文献依据】马铃薯目标领域的现状是单时期差异比较，而非分布/轨迹推断 P1 对马铃薯盆栽材料设置缺氮/正常/足氮三水平，整合生理、匍匐茎转录组与代谢组，鉴定 2756 个氮响应 DEGs 与 600 个 DAMs，相关分析锁定 α-亚麻酸代谢（9 个关键 DEGs）、淀粉与蔗糖代谢（16）、氮代谢（7）、ABC 转运体（16）等通路。该设计为单时期、组织混合（bulk）、横断面比较，无时期序列、无单细胞分辨率、无生物学轨迹；结论为相关/共表达层面，机制为推断。这正对应用户所述'已有方法'基线。迁移意义：P1 的通路清单可直接作为 OT 状态空间与代价矩阵的生物学先验，其'处理组间'设计可改造为静态 Wasserstein 距离比较；但其 bulk 混合信号会稀释细胞类型特异状态，不能直接做轨迹推断。 依据：[P1]

【文献依据】植物领域已有 OT 用于发育轨迹与命运概率的先例，马铃薯领域查新需限定范围 P4 构建 >11 万细胞的拟南芥根器官级单细胞图谱，明确采用最优传输（StationaryOT）推断发育轨迹、计算细胞命运概率并识别候选调控因子，重发现 MYB36、SCR、JKD、GLABRA2、CAPRICE、RHD6 等已知调控子，并用 scr/shr 突变体揭示皮层/内皮层混合身份与跨分化现象。P5 对四倍体马铃薯 'Atlantic' 钩状匍匐茎做单核多组学（snRNA-seq+snATAC-seq 同一核），20079 个核分为 27 簇、注释 10 种细胞类型，用 Slingshot 拟时序解析原形成层向木质部四条分化路径。P4 证明 OT 已用于植物器官发育；P5 说明马铃薯单细胞研究目前使用 Slingshot 而非 OT，但不能据此推断整个马铃薯领域未用 OT。因此撤回首轮'首次尝试'及'整个领域未用 OT'的说法；创新性表述应限定为'在选定 5 篇文献范围内，马铃薯单细胞轨迹分析以 Slingshot 为主，OT 在马铃薯块茎发育中的静态分布比较应用需进一步系统查新'。 依据：[P4] [P5]

【迁移推论】M4 静态分布比较是本次验收案例下唯一可讨论的 OT 迁移路径 基于 P2/P3 的方法前提与 P1 的目标领域现状，M4（Wasserstein 距离/重心作为处理或材料间静态经验分布比较）是唯一不与当前数据条件直接冲突的映射。其核心要件包括：定义概率测度（样本特征向量的归一化与质量分配）、代价函数（可结合 P1 通路清单或全特征空间）、足够独立生物重复、可比组织与批次。该路径不声称恢复时间轨迹、细胞命运或单细胞状态分布，仅回答'分布层面差异是否比常规距离更稳定、更可解释'。若数据要件不满足，M4 同样触发停止条件。 依据：[P1] [P2] [P3]

【迁移推论】bulk 去卷积只能估计细胞类型比例，不能恢复单细胞状态分布或轨迹 P5 提供了 Atlantic 钩状匍匐茎 10 种细胞类型的单核多组学参考，可在组织、品种、发育时期与标记基因相容时作为去卷积参考。但去卷积输出为细胞类型比例估计，不等于还原单细胞状态分布，更不支持时间轨迹或命运概率推断。若将比例估计误作单细胞分辨率证据，会夸大 M1 的成立程度。因此 M1 维持 pending：仅在后续获得单细胞数据或可靠参考且满足相容性条件时，才可能进入状态分布层面的 OT 分析。 依据：[P5]

【迁移推论】基线与增量评估框架已定义，但当前仅停留在设计层面 若数据条件满足，M4 的验证逻辑为：以差异表达/差异代谢物、常规距离（欧氏/马氏/PCA 距离）为基线，比较 Wasserstein 距离/重心在稳定性（重采样/扰动）、可解释性（是否对应 P1 通路或已知生物学）与增量信息（是否提供基线未捕获的分布结构）上的表现。若 Wasserstein 距离相对常规距离无稳定增量，或概率测度/代价函数定义失败，则停止 OT 实施。当前因无真实数据，该框架仅为设计审查，不构成已完成的计算验证。 依据：[P1]

05 / 最小验证方案与判定标准

  1. 最小验证步骤（条件满足后执行）：1) 样本设计核查：确认每组独立生物重复数、配对/批次结构、采收组织与时期一致性；任一要件缺失或不可比即停止。2) 数据形态核查：确认 RNA-seq 为原始计数或已归一化矩阵，代谢组为峰面积/相对/绝对定量，两组学是否同一样本配对；据此定义概率测度与归一化策略。3) 概率测度与代价函数定义：以可比样本特征向量构成经验分布，候选代价函数结合 P1 通路清单（淀粉-蔗糖代谢、α-亚麻酸代谢、氮代谢、ABC 转运体）或全特征空间，明确质量分配与距离定义。4) 基线计算：差异表达/差异代谢物、常规距离（欧氏/马氏/PCA 距离）及其重采样稳定性。5) OT 计算与比较：在相同重采样方案下计算 Wasserstein 距离/重心，评估稳定性、可解释性与增量。6) 停止判定：若 Wasserstein 距离无稳定增量、或测度/代价定义失败、或重复/批次条件不满足，停止 OT 并输出暂停实施结论。
  2. 停止条件：若任一分组独立生物重复<2、批次/组织不可比、概率测度或代价函数无法定义、或Wasserstein距离相对常规距离无稳定增量,则停止OT实施并转入文献/设计审查报告。

06 / 方案评估

可行性 · 待验证 M4 静态分布在概念上可行，但缺乏实施必需的输入条件：每组独立生物重复数、是否配对、批次结构、采收组织/时期一致性、RNA-seq 数据形态（原始计数或归一化矩阵）、代谢组定量方式（峰面积/相对/绝对定量）、两组学是否同一样本配对、待比较分组均未提供。概率测度与代价函数尚停留在草案层面，未经验证。根据已确认的停止条件，任一要件缺失即应暂停 OT 实施。

创新性 · 一般 首轮“首次尝试”及“整个马铃薯领域未用 OT”的过度推断已被撤回。基于当前 5 篇文献，P4 已将 StationaryOT 用于拟南芥根单细胞图谱的命运概率推断，P5 在马铃薯钩状匍匐茎使用 Slingshot 而非 OT。在选定范围内，将 OT/Wasserstein 距离用于马铃薯块茎发育的静态组学分布比较尚未见报道，具备领域迁移层面的新颖性；但这不是方法学原创，且是否为首例需另行系统查新确认。

证据完整性 · 一般 P1-P5 的题录、摘要与关键方法段落已按证据等级标注（全文级、摘要+方法章节级、摘要级），核心主张均有来源支持。但证据边界清晰：P4/P5 的细胞图谱与轨迹结论基于单细胞数据，不能直接外推至 bulk；P1 为单时期横断面比较，无时间序列。去卷积只能估计细胞类型比例，不能恢复单细胞状态分布。当前证据足以支持方法适用性审查，不足以支持 OT 计算实施。
